MultiStore Mailer is the email-sending component of the MultiStore system, a private store-management project. It sends transactional emails only (for example, sign-in or verification codes) from one dedicated Gmail account, using the Gmail "send" permission.

It is not a public service. It is used by the MultiStore system owner only, with a single approved Google account. No one else can connect to it.

Source code: github.com/eng-hanysabry/multistore
